# Dr. Ladipo — Luxury Medical Website

Next.js + TypeScript + Tailwind CSS + shadcn-style UI, designed for Vercel.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Notes

- Patient before/after images, Instagram media, testimonials, and other patient-identifying content are intentionally placeholders until approved for web publication.
- The contact form is UI-only and should be connected to an approved CRM/email/form provider before production.
- Replace placeholder media in `components/placeholder-image.tsx` with approved practice-owned photography/video.
- Review all medical copy with the practice before publishing.

## Deployment

Import the repository into Vercel. No special build configuration is required.
